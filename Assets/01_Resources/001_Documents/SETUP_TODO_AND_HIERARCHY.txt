5) SceneFlow 순서 (씬 전환 흐름)
============================================================

전체 흐름 다이어그램:

  ┌──────────┐  부팅 완료    ┌───────────┐
  │BootScene │ ────────────► │TitleScene │ ◄──────────────┐
  └──────────┘ (BootLoader)  └─────┬─────┘                │
                                   │                      │
            ┌──────────────────────┼──────────────────┐   │
            │ Continue / NewGame   │ Credits          │ Quit
            ▼                      ▼                  ▼
       ┌───────────┐          ┌────────────┐    Application.Quit
       │LobbyScene │ ◄──┐     │CreditsScene│
       └─────┬─────┘    │     └──────┬─────┘
             │          │            │ 끝/Skip
   ┌─────┬───┴────┬───┐ │            └────────────────────┘
   ▼     ▼        ▼   ▼ │ 작업/전투 종료
 [Battle][Analysis][Dissection][Assembly]
   │     │        │   │ │
   └─────┴────────┴───┴─┘
                          (Lobby → Title 메뉴로 나가기 동선도 가능)

씬 진입/진출 매트릭스:

| 씬                  | 진입 (어디서)                | 진출 (어디로)                          |
|---------------------|------------------------------|----------------------------------------|
| BootScene           | Application 시작             | TitleScene (자동)                       |
| TitleScene          | Boot / Lobby 이탈 / Credits 끝 | Lobby / Credits / Quit                |
| LobbyScene          | Title (NEW/CONT) / Game 종료 | Battle / Analysis / Dissection / Assembly / Title |
| GameBattleScene     | Lobby                        | Lobby (결과 처리는 [B])                 |
| GameAnalysisScene   | Lobby                        | Lobby                                   |
| GameDissectionScene | Lobby                        | Lobby                                   |
| GameAssemblyScene   | Lobby                        | Lobby                                   |
| CreditsScene        | Title                        | Title                                   |

씬 전환 트리거 (호출 패턴):

  공통 호출 패턴:
    GameRoot.Instance.SceneFlow.NextScene(<TargetSceneListConfig>);
    GameRoot.Instance.SceneFlow.Load();

  - BootScene → TitleScene
      BootLoader.BootAsync()
        → GameRoot.InitializeIfNeeded()
        → Settings.LoadAndApplyAsync()
        → SceneFlow.CurrentScene(_nextSceneConfig)
        → SceneManager.LoadScene(...)   // 부트 한정 동기 로드
      ※ 추후 BootLoader도 SceneFlow.NextScene + Load 패턴으로 통일 검토 [?]

  - Title → Lobby (Continue)
      Title.ContinueButton (D-4, D-8 후 활성)
        → 슬롯 선택 UI → SceneFlow.NextScene(LobbyScene) + Load()

  - Title → Lobby (New Game)
      Title.NewGameButton (D-4)
        → 덮어쓰기 경고 Popup(D-1)
        → 새 슬롯 생성(D-8)
        → SceneFlow.NextScene(LobbyScene) + Load()

  - Title → 옵션 (씬 전환 없음)
      Title.SettingsButton (D-4)
        → GameRoot.Instance.Options.Open()

  - Title → Credits  ([?] 진입 버튼 노출 여부 결정 필요)
      Title.CreditsButton
        → SceneFlow.NextScene(CreditsScene) + Load()

  - Title → Quit
      Title.QuitButton (D-4)
        → 확인 Popup(D-1) → Application.Quit()

  - Lobby → 작업/전투 씬
      Lobby.BattleButton     → SceneFlow.NextScene(GameBattleScene) + Load()
      Lobby.AnalysisButton   → SceneFlow.NextScene(GameAnalysisScene) + Load()
      Lobby.DissectionButton → SceneFlow.NextScene(GameDissectionScene) + Load()
      Lobby.AssemblyButton   → SceneFlow.NextScene(GameAssemblyScene) + Load()

  - Lobby → Title (메뉴로 나가기)  ([?] 동선 노출 여부 결정 필요)
      Lobby.BackToTitleButton
        → 저장 확인 Popup(D-1)
        → SceneFlow.NextScene(TitleScene) + Load()

  - Game* → Lobby
      각 게임 씬의 "마치기/돌아가기" 또는 결과 화면 종료
        → SceneFlow.NextScene(LobbyScene) + Load()
      ※ 결과 화면 구성/통계 표시는 [B] 시스템 기획 대기

  - Credits 종료
      자동 종료 또는 Skip 버튼
        → SceneFlow.NextScene(TitleScene) + Load()

게임 씬 일시정지 흐름 (D-5 PauseMenu):

  ESC ─► PauseMenuController.Open()
        ├ Resume          → 메뉴 닫기 + Time.timeScale = 1
        ├ Settings        → Options.Open()  (씬 전환 없음)
        ├ Title로 나가기  → 저장 확인 Popup
        │                   → SceneFlow.NextScene(TitleScene) + Load()
        └ Quit            → 확인 Popup → Application.Quit()
  ※ 옵션 화면이 떠있을 땐 ESC가 옵션 닫기에 우선 사용됨 (모달 스택 D-1)
