0) 전제(컨벤션)
============================================================
- 전역 루트는 GameRoot 1개만 사용
- GameRoot는 자동 생성 금지(반드시 프리팹/씬 배치)
- 컨트롤러/팩토리는 생성하지 않고 GameRoot 하위에 “프리팹으로 붙여둠”
- 전역 초기화는 Start에 두지 않고 BootScene의 BootLoader가 GameRoot.InitializeIfNeeded()를 호출

3) 하이어라키 추천(프리팹/씬 구성)
============================================================

[BootScene]
BootScene
├─ Boot
│  └─ BootLoader
└─ GameRoot (Prefab, DontDestroyOnLoad)
   ├─ _ControllersRoot (Transform 할당용)
   │  ├─ SceneFlowController
   │  ├─ SaveController
   │  ├─ SettingsController
   │  ├─ InputController
   │  └─ AudioController (있으면 권장)
   ├─ _UIRoot (Prefab)
   │  ├─ Canvas (Screen Space - Overlay)
   │  │  ├─ FadePanel
   │  │  ├─ PopupRoot
   │  │  └─ ToastRoot
   │  └─ EventSystem
   └─ _Runtime (옵션)
      ├─ DebugConsole
      └─ FPSCounter

[TitleScene]
TitleScene
├─ Camera (Cinemachine 또는 기본 Camera)
├─ Lighting (Directional Light, Volume)
└─ UI
   └─ TitleView (Prefab)
      ├─ Logo
      ├─ Menu
      │  ├─ ContinueButton
      │  ├─ NewGameButton
      │  ├─ SettingsButton
      │  └─ QuitButton
      └─ VersionText

[LobbyScene]
LobbyScene
├─ Camera (Lobby 프리셋)
├─ Lighting
├─ Environment (작업대/공방 더미)
└─ UI
   └─ LobbyView (Prefab)
      ├─ BattleButton
      ├─ AnalysisButton
      ├─ DissectionButton
      └─ AssemblyButton

[GameDissectionScene / GameAssemblyScene] (작업 씬 프로토타입)
GameDissectionScene (또는 GameAssemblyScene)
├─ CameraRig (오빗/팬/줌)
├─ Workbench (테이블/배경)
├─ DummyCreature (파트 프리팹 1개)
└─ UI
   └─ WorkView
      ├─ PartInfoPanel
      └─ ToolPanel (더미)
